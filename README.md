## ✨ ฟีเจอร์หลัก (Key Features)

### 💬 1. LiveChat TikTok Reader
ระบบอ่านแชท TikTok แบบเรียลไทม์ที่ช่วยให้คุณไม่พลาดทุกการติดต่อสื่อสาร
- **Real-time Connection**: เชื่อมต่อกับ TikTok Live ได้ทันทีเพียงใส่ชื่อผู้ใช้
- **Smart TTS (Thai/English)**: ระบบอ่านข้อความแชทและชื่อผู้มอบของขวัญอัตโนมัติด้วยเสียง AI คุณภาพสูง
- **Transparent Overlay**: หน้าจอแชทโปร่งใสสำหรับนำไปซ้อนใน OBS หรือ TikTok Live Studio
- **Event Alerts**: แจ้งเตือนเมื่อมีคนกดติดตาม (Follow), ส่งของขวัญ (Gift), หรือแชร์สตรีม

### 🎭 2. Reactive Avatar
เปลี่ยนเสียงของคุณให้เป็นอนิเมชั่นตัวละครอาวาตาร์ เพิ่มสีสันให้สตรีมโดยไม่ต้องใช้กล้อง
- **Voice Activation**: อาวาตาร์ขยับปากตามระดับเสียงไมโครโฟนของคุณ
- **Customizable States**: รองรับรูปภาพหลายสถานะ (Idle, Talking, Blinking)
- **Sensitive Control**: ปรับแต่งความไว (Sensitivity) และความหน่วงในการตอบสนองได้อิสระ
- **Native Screen Capture**: หน้าจอ Overlay แยกสำหรับนำไปใช้งานในโปรแกรมสตรีมได้ทันที

## 🛠 การติดตั้งและใช้งาน (Installation & Usage)

### สำหรับผู้ใช้งาน (Users)
1. ดาวน์โหลดไฟล์ติดตั้งจากหน้า [Releases](https://github.com/JJacKTH/CreatorSuite/releases)
2. ติดตั้งโปรแกรมและเปิดใช้งาน
3. ตั้งค่าไมโครโฟนและเชื่อมต่อกับ TikTok เพื่อเริ่มใช้งาน

### สำหรับนักพัฒนา (Developers)
```bash
# Clone repository
git clone https://github.com/JJacKTH/CreatorSuite.git

# เข้าไปยังโฟลเดอร์
cd CreatorSuite

# ติดตั้ง dependencies
npm install

# รันในโหมดพัฒนา (Development)
npm run dev

# สร้างไฟล์ติดตั้ง (Build)
npm run build
```
